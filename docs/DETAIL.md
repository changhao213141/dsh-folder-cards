# 文件夹卡片侧栏

把左侧栏的「工作区」区（`sidebar.workspaces` 座位）换成文件夹卡片。其余部分——品牌行、新会话按钮、底部设置、右侧对话区——保持原生不动。

## 形态

- **两列网格**：每行两张卡片，卡片宽高比 **3:4**（竖边比横边长一点）；两张卡加间隙正好铺满侧栏宽度，窗口变窄时卡片等比缩小。
- **默认外观**：上方文件夹图标，下方文件夹名称（取工作区标题，退回路径的最后一段，都没有时显示「未命名工作区」），名称过长时单行省略。
- **插入图片**：卡片右上角在悬停/聚焦时出现两个小按钮——「插入图片」与「恢复默认外观」（触屏设备上常显）。图片按最长边 320px 转成 WebP/PNG 后存在浏览器本地，刷新、重启都还在；选「恢复默认外观」立刻回到文件夹图标。存储失败会提示原因，而不是静默失败。
- **点卡片**：点下去时从指针位置荡开一圈水波（一枚柔光核 + 两道错开 110ms 的涟漪环，640ms 扩散淡出），约 150ms 后下一级内容浮现——会话面板带 240ms 的淡入上浮动画。**点返回时水波反向收拢**（环由外向内缩回指针处、同步淡出，160ms 后卡片网格淡入回来），进出两侧都是同一套水滴语言。系统开了「减少动态效果」时直接切换，不播动画。面板内容：一行一个会话（标题 + 相对时间，运行中的会话左侧圆点常亮），最上面一行是「＋ 新会话」，再上面是 **返回** 按钮，返回后键盘焦点落回原来那张卡片。
- **滚动**：只有「工作区」标题行**以下**的卡片区滚动——标题行连同侧栏上方的品牌行、新会话按钮都定住不动。做法是把本区域的高度按“外层侧栏视口实际溢出多少就削掉多少”闭环校正到恰好占满，外层视口因此完全不产生滚动，整条侧栏保持固定。区域内部用侧栏自带的分段滚轮器，滚到底就是列表真正的底部（底部留 28px 内边距，最后一张卡片完整可见，不会被底部渐隐条压住）。右侧有一条细滑块，平时隐藏，鼠标移进卡片区才淡入（150ms 快速浮现），移出后慢慢淡出（450ms），拖动中或键盘聚焦时保持显示，可拖动、点空白轨道跳转、方向键 / PageUp / PageDown / Home / End 操作。内容放得下时滑块不出现。
- **搜索**：标题行右侧放大镜切成输入框，输入即搜（250ms 防抖）：先匹配文件夹标题与路径，再匹配所有会话标题，最后接 Host 的内容索引（`ctx.sessions.search`）补上正文命中，结果一行一条（标题 + 所在文件夹或命中片段），回车/点击直达；Esc 或「×」关闭。搜不到时给出明确空状态。
- **视图选项**：标题行右侧的滑杆按钮打开一个小面板，可切换卡片排序——「默认顺序」（工作区登记顺序）或「最近活跃」（按该文件夹里最近更新的会话倒序）。选择存在浏览器本地，下次打开沿用；同时会记住上次打开的文件夹，重进 DSH 直接回到那里。
- **降级菜单**：如果外壳某天不再提供原生会话菜单（`contextMenus` 的 `session` 目标没有注册项），行尾「⋯」不会变成死按钮，而是改用插件自带的小菜单——行内重命名（Enter 保存 / Esc 取消）、分叉、复制会话 ID、归档 / 取消归档；置顶没有公开 API，降级时这一项不提供。
- **会话操作**：会话行上右键（或行尾悬停出的「⋯」按钮）打开原生会话菜单——重命名、置顶/取消置顶、分叉、复制会话 ID、归档/取消归档，菜单项随远端权限与当前状态自动增减；重命名弹窗、归档确认这些原生浮层照常工作。文件夹卡片上右键则是原生工作区菜单（重命名 / 删除）。
- **归档会话**：文件夹里的已归档会话不再消失，列表底部有一行「已归档 N 个」，展开即可看到，点一条即恢复归档。
- **未分组会话**：不属于任何工作区的会话（没有工作区时新建的会话、或工作区被删后留下的会话）单独成一张「未分组」卡片，不会凭空消失。
- **加载与出错**：工作区还在加载时显示「正在加载工作区…」，加载失败显示错误提示，而不是误报「还没有工作区」。
- **侧栏折叠**：折叠成窄栏时卡片退化成单列图标按钮，点一下先展开侧栏再进入该文件夹。
- **新建工作区**：网格顶部标题行右侧的「＋」调系统目录选择器，选中的目录直接登记为工作区。

## 数据与存储

- 卡片图画存在浏览器 `localStorage` 的 `dsh.folderCards.v1`：`{ "version": 1, "images": { "<workspaceId>": "data:image/..." } }`。
- 视图偏好存在 `dsh.folderCards.prefs.v1`：`{ sort: "manual" | "recent", lastOpenId }`，删除该键即恢复默认（默认顺序、不记忆文件夹）。
- 工作区、会话列表、置顶与归档状态都实时读 DSH 自己的 Client 服务（`useWorkspaces` / `useSessions` / `useSessionStatus`），本插件不写任何官方状态；禁用或卸载后原生工作区列表原样回来。

## 已知限制

- 接管整个 `sidebar.workspaces` 座位后，原生区头里的 **视图选项**（分组/排序弹层）不再出现；别的插件挂在 `sidebar.session.row.*` 上的行内装饰也不会渲染（原生右键菜单与浮层对话框仍然可用）。
- 包声明了 `engines.dsh: ">=0.2.2-rc.1 <0.3.0"`，与 DSH 版本不匹配时插件管理器会拒绝安装/激活；尺寸自适应仍是运行时测量外壳几何，外壳布局大改时优先怀疑这一段。
- 已归档会话默认不列出（与原生默认视图一致），需要时请临时切回原生侧栏。
- 子代理会话不出现在卡片列表里；当前会话的空白草稿由「＋ 新会话」一行代替原生侧的草稿行。
- 只提供中文与英文两套界面文案，其它语言回退到英文。
