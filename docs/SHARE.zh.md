## 2. 正文版（论坛、群里长文、GitHub Discussions）

> **dsh-folder-cards：给 DeepSeek Harness 的侧栏换成文件夹卡片**
>
> 平时 DSH 的工作区一多，左侧就是一长串文字，扫起来慢，也看不出哪个文件夹最近动过。我把这块改成了卡片：
>
> - 两列 3:4 竖版卡片，默认文件夹图标 + 名称，**可以给每张卡插一张图**当封面；
> - 点卡片，从鼠标位置荡开一圈水波，然后浮现这个文件夹的会话列表；点返回，水波反着收拢回去；
> - 卡片区单独滚动，上面的品牌行、新会话按钮、「工作区」标题行都固定不动，右侧有一条悬停才出现的细滑块；
> - **搜索**（文件夹 → 会话标题 → 正文命中）、**会话右键菜单**（重命名/置顶/分叉/复制 ID/归档，直接复用原生菜单）、**已归档会话展开恢复**、**排序（默认 / 最近活跃）** 都在；
> - 全部用 DSH 主题令牌，明暗主题自动跟随；不写任何官方状态，禁用/卸载后原生侧栏原样回来。
>
> 完全是我自己用着顺手才做的，所以更希望有人一起把它做扎实。目前最想被帮到的：
>
> 1. **真实使用反馈和截图**——尤其是不同 DSH 版本、不同屏幕宽度下的表现；
> 2. 区域高度目前是**运行时测量外壳几何**算出来的，比较脆，希望能换成更稳的方案；
> 3. 拖拽排序、视图选项（分组/排序弹层）、搜索命中高亮、更多语言；
> 4. 一套最小冒烟测试。
>
> 仓库：`https://github.com/<你的用户名>/dsh-folder-cards`（MIT）。用着别扭、想法不对、或者代码写得很怪，都欢迎直接开 issue 骂醒我，谢谢。

## 3. Issue / PR 里的「求帮助」模板

> 这个插件现在能日常用，但还有几块我没把握：
>
> - **尺寸自适应**：`src/60-component.js` 的 `measureAvail()` 靠读外层 `scrollHeight - clientHeight` 反向削高度。如果 DSH 侧栏改用别的排版方式，这块会先坏。
> - **菜单耦合**：会话菜单依赖 ui-workspace 注册的 `contextMenu` 目标；我加了探测和降级菜单，但降级里没有「置顶」（没有公开 API）。
> - **没有测试**：目前只有构建产物的语法检查和手测。
>
> 任何一块有更干净的做法，都欢迎指路或直接 PR。
